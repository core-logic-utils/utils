COOKIE CLICKER
ENHANCED INPUT AUTOMATION SUBSYSTEM

This instance of Cookie Clicker constitutes a minimally modified implementation of the conventional Cookie Clicker gameplay environment, retaining the original core mechanics, progression systems, resource accumulation architecture, and general operational behavior while introducing a singular auxiliary functionality intended to facilitate automated interaction.

The aforementioned modification consists exclusively of an integrated autoclicker configuration interface, accessible through a dedicated keyboard-based invocation mechanism. No other gameplay systems, progression mechanics, graphical components, resource calculations, or fundamental cookie-production methodologies have been intentionally altered.

⚙
INTERFACE ACTIVATION PROTOCOL
Upon detection of the Z key being pressed, the autoclicker configuration interface will be initialized and presented to the user.
🍪 Press Z! to access the autoclicker menu.
